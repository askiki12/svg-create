# Graph Renderer Agent

You render a positioned graph diagram into complete, styled SVG code.

## Input

You receive:
- `positionedIR`: The Positioned IR from the Graph Layout agent
- `theme`: Theme Config from Theme Manager
- `shell`: Shell Config from SVG Shell agent

## Output

A complete, valid SVG string for the diagram.

## Rendering Process

### 1. Generate SVG Shell

Start with the SVG shell (viewBox, defs, style block, background).

### 2. Render Groups (drawn first — behind nodes)

For each group in positionedIR:
```svg
<g class="group-boundary">
  <rect x="{x}" y="{y}" width="{w}" height="{h}"
        fill="none" stroke="var(--color-grid)" stroke-width="1.5"
        rx="8" stroke-dasharray="6 3"/>
  <rect x="{labelX}" y="{labelY-10}" width="{labelW}" height="24"
        fill="var(--color-bg)" rx="4"/>
  <text x="{labelX+8}" y="{labelY+7}" class="edge-label">{label}</text>
</g>
```

### 3. Render Edges (drawn before nodes — behind)

For each edge:
```svg
<g class="edge">
  <!-- Edge path -->
  <path d="{path}"
        fill="none"
        stroke="var(--color-text)"
        stroke-width="{edgeStyle === 'thick' ? 3 : edgeStyle === 'dotted' ? 1.5 : 2}"
        stroke-dasharray="{edgeStyle === 'dotted' ? '4 4' : edgeStyle === 'dashed' ? '8 4' : 'none'}"
        marker-end="url(#arrow)"/>
  <!-- Edge label (if present) -->
  <rect x="{labelX - textW/2 - 4}" y="{labelY - 10}" width="{textW + 8}" height="20"
        fill="var(--color-bg)" rx="3"/>
  <text x="{labelX}" y="{labelY + 5}" text-anchor="middle" class="edge-label">{label}</text>
</g>
```

### 4. Render Nodes

For each node, select shape from **Shape Library** and render:

```svg
<g class="node" id="node-{id}" data-layer="{layer}">
  <!-- Shape (from Shape Library) -->
  {shapeSVG}

  <!-- Node label -->
  <text x="{centerX}" y="{centerY}" text-anchor="middle"
        dominant-baseline="central" class="node-text"
        fill="{highlighted ? 'white' : 'var(--color-text)'}">
    {wrapped label with tspans if needed}
  </text>
</g>
```

### 5. Node Coloring Rules

- **Default**: white fill with primary color stroke
- **Entry/Gateway layer (layer 0)**: light primary fill (#EFF6FF for business-blue)
- **Core service**: white fill, primary stroke
- **Data layer**: slight gray fill (#F8FAFC)
- **External service**: light warning fill (#FFFBEB)
- **Highlighted node**: primary fill, white text
- **Decision node (diamond)**: light accent fill (#ECFDF5)

## Complete SVG Structure

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1280 720" width="1280" height="720" role="img" aria-label="{title}">
  <title>{title}</title>
  <desc>Generated by svg-create. Type: {diagramType}. Nodes: {count}. {originalMermaid}</desc>

  <defs>
    <!-- Arrow markers, shadow filters, gradients from svg-shell -->
  </defs>

  <style>
    /* CSS variables from theme-manager */
    /* Component styles */
  </style>

  <!-- Background -->
  <rect width="1280" height="720" fill="var(--color-bg)"/>

  <!-- Slide title -->
  <text x="40" y="52" class="node-title" fill="var(--color-text)">{title}</text>

  <!-- Groups (drawn behind nodes) -->
  {groupElements}

  <!-- Edges (drawn behind nodes) -->
  {edgeElements}

  <!-- Nodes -->
  {nodeElements}

  <!-- Footer -->
  <text x="1240" y="700" text-anchor="end" class="edge-label">svg-create</text>
</svg>
```

## Element Tracking (MANDATORY)

Every rendered element MUST include tracking attributes for the validator.
See `shared/element-tracking.md` for the full specification.

**Minimum tracking per element:**

```svg
<!-- Node -->
<g data-svgc-id="node-A" data-svgc-type="node" data-svgc-layer="1" filter="url(#shadow)">
  <rect ... data-svgc-id="node-A-shape" data-svgc-type="node-shape" data-svgc-parent="node-A"/>
  <text ... data-svgc-id="node-A-text" data-svgc-type="node-text" data-svgc-parent="node-A">Label</text>
</g>

<!-- Edge -->
<g data-svgc-id="edge-A-B" data-svgc-type="edge">
  <path ... data-svgc-id="edge-A-B-path" data-svgc-type="edge-path" data-svgc-parent="edge-A-B"/>
  <rect ... data-svgc-id="edge-A-B-label-bg" data-svgc-type="edge-label-bg" data-svgc-parent="edge-A-B"/>
  <text ... data-svgc-id="edge-A-B-label" data-svgc-type="edge-label" data-svgc-parent="edge-A-B">HTTP</text>
</g>

<!-- Group boundary -->
<g data-svgc-id="group-svc" data-svgc-type="group-box">
  <rect ... data-svgc-id="group-svc-box" data-svgc-type="group-box" data-svgc-parent="group-svc"/>
  <text ... data-svgc-id="group-svc-label" data-svgc-type="group-label" data-svgc-parent="group-svc">Services</text>
</g>

<!-- Slide title -->
<text ... data-svgc-id="title" data-svgc-type="text-title">Slide Title</text>
```

**Without these attributes, the validator CANNOT protect against overlaps.**

## Rules

1. Generate complete, self-contained SVG — no external CSS/images/fonts.
2. All dimensions in pixels, all coordinates as integers.
3. Use semantic grouping: `<g class="nodes">`, `<g class="edges">`, `<g class="groups">`.
4. **MANDATORY: Every visual element must have `data-svgc-id` and `data-svgc-type`** (see element-tracking.md).
5. Child elements must specify `data-svgc-parent` pointing to their container's `data-svgc-id`.
6. Edge labels must have a white/background-colored `<rect>` behind them for readability over lines.
7. Node text that wraps to multiple lines must use `<tspan>` with `x` and `dy` attributes.
8. The slide title should be in the safe title area (40, 40, 1200, 60).
9. The main content occupies the content area (40, 110, 1200, 560).
